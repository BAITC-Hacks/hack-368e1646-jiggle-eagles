# Money Graph working guide

**Money Graph — HackAlem AI · Finance · Freedom.** Build a local AML investigation tool from the organizer's anonymized July 2026 transaction network. [README](../../README.md) distinguishes the working connectivity starter from planned graph functionality.

## Workflow

1. [Selected task](task-selection.md) and [requirements](requirements.md): confirmed scope, fixed exports, acceptance and open decisions.
2. [Data contract](data-profile.md) and [domain guide](../money-graph/README.md): schemas, collection limits and interpretation.
3. [Task breakdown](task-breakdown.md), [architecture](../money-graph/architecture.md) and [execution plan](execution-plan.md): first complete journey and implementation order.
4. [Assignments](agent-assignments.md): exact ownership before feature work or delegation.
5. [Integration verification](integration-verification.md) and [submission checklist](submission-checklist.md): actual evidence and five-minute demo.

[Deployment readiness](deployment-readiness.md) is optional hosting guidance. Core reproduction is local; no public deployment or paid service is required by the task brief.
