# Hackathon working guide

Start with the current official brief, [project setup](../../README.md) and [repository rules](../../AGENTS.md). This index links to the working documents; it does not establish event requirements.

## Workflow

1. [Task selection](task-selection.md): compare feasible tasks and record the team's choice.
2. [Task breakdown](task-breakdown.md): define the user scenario, data semantics and interfaces.
3. [Execution plan](execution-plan.md): schedule implementation, integration and verification.
4. [Submission checklist](submission-checklist.md): verify deliverables and the submitted revision.

Keep decisions and acceptance criteria in [requirements](requirements.md) and file ownership in [assignments](agent-assignments.md). Use [integration verification](integration-verification.md) for local checks and launch procedures, [deployment readiness](deployment-readiness.md) for hosting, and [energy references](../energy/README.md) for domain work.
