## Naming and timestamps

Use a descriptive lowercase topic followed by local 24-hour time: `<topic>-HH-MM.md` (for example, `localization-16-07.md`). Record the full date, time and timezone inside each entry. Use Asia/Almaty (UTC+05:00). If a filename already exists, append the full date before the time: `<topic>-YYYY-MM-DD-HH-MM.md`.

Timestamps on migrated entries identify their reorganization, not when the original development or verification happened. Future work should receive its own descriptive entry and a link here.
